&#x20;CinemaHub



CinemaHub is a movie discovery and browsing website that allows users to explore movies across different genres.



&#x20;Features

\- Browse movies across different genres, including action, comedy, romance, and thriller.

\- Explore movie collections through dedicated genre pages.

\- User login and signup interfaces.

\- About and contact pages.

\- Movie-focused interface with images and styling.



&#x20;Technologies Used

\- HTML

\- CSS

\- PHP

\- MySQL



&#x20;Project Structure

\- `index.php` – Main entry point.

\- `login.php` and `signup.php` – Authentication-related pages.

\- HTML files – Movie genre and informational pages.

\- CSS files – Website styling.

\- JPG images – Movie images and website visuals.



&#x20;How to Run

1\. Install a local PHP/MySQL environment such as XAMPP.

2\. Place the project folder inside the XAMPP `htdocs` directory.

3\. Start Apache and MySQL from the XAMPP Control Panel.

4\. Configure the database settings in `config.php`.

5\. Open `http://localhost/cinemahub/` in your browser.
